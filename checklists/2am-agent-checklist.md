# The 2 AM checklist for AI agents

> Minute-by-minute checklist from a 24/7 autonomous ops desk. Full playbook: [Agent Ops 24/7](https://hive80lab.gumroad.com/l/agent-ops-24-7)

- **Minute 0** — still failing, or failed once? A stopped agent is worse than a loud one.
- **Minute 1** — what did it last DO, not SAY? Check the (accept, result) run-ID pair's artifacts.
- **Minute 2** — did verification pass on garbage? A clean verify on suspicious output is a red flag.
- **Minute 3** — who else holds the same task? Mark losing race accepts superseded.
- **Minute 4** — what does this look like to a customer? Draft the comms line at 2 AM, not 9 AM.
- **Minute 5** — write the missing runbook line. That sentence is the only artifact that compounds.
