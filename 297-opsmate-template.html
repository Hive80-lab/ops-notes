What is OpsMate?

OpsMate is your on-call concierge: a single HTML file you keep open in your browser (bookmark it, make it a PWA) that gives you instant answers to the questions you ask 2am every week.

Use cases

  • Before an incident: "What's the escalation ladder for AWS S3 outages?" — you see the exact flow
  • During an incident: "What are the mandatory communication templates?" — you copy-paste the pre-written line
  • After an incident: "What's the remediation checklist for data loss?" — you get the step-by-step verification
  • At board meetings: "What's the current incident response maturity?" — you pull the incident taxonomy framework

Structure

  1. Incident taxonomy: business impact, category matrix, root cause categorization
  2. Escalation mesh: tiers, Slack structure, rotation cadence
  3. Communication templates: status page, customer email, internal update
  4. Remediation checklists: verification steps, before/after proofs
  5. After-action reporting: TEMPLATE + reviewers + due date

How to use

  • Download the HTML file (it's just text — no server required)
  • Bookmark it in your browser
  • Make it your browser's homepage or PWA
  • Update quarterly with new incident types, tools, and contacts

Why this exists

We've seen too many on-call people guessing at what to do: wrong escalation path, wrong communication line, wrong remediation step. This template removes that guessing. It's one file you keep open, and it's always up to date.
