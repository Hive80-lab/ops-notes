Incident Response Pillars — 5 New Frameworks

Build a complete incident-response system with 5 new frameworks: taxonomy, escalation, playbooks, simulations, and vendor coordination.

Pillar 1: Incident Taxonomy Framework

Classify incidents by business impact and technical category to match response resources.

Checklists:

  • Business Impact Checklist — Classify incidents by business impact (revenue, data, trust, compliance, brand)
  • Category Matrix — Map incidents to technical categories (availability, security, performance, functional, data, third-party)
  • Root Cause Categorization — Systematically categorize root causes to prevent recurrence

Pillar 2: On-Call Escalation Mesh

Define structured escalation for different severity and impact levels.

Checklists:

  • Escalation Path Tiers — Define tiers, SLAs, and escalation paths (Tier 1: 15 min, Tier 2: 30 min, Tier 3: 1 hour)
  • Slack Structure — Define channels, roles, and message conventions (P1-P4)
  • Rotation Cadence — Define rotation schedules, contacts, and standby processes (4-week rotations)

Product links: Ops Starter Kit Vol 2 (A$27)

Pillar 3: Playbook Triage Matrix

Quick decision flow to select the right playbook for any incident.

Checklists:

  • Triage Decision Flow — Match incident type, severity, and category to the right playbook
  • Selection Rules — Define clear rules for selecting the correct playbook
  • Playbook Matrix — Quick-reference matrix matching incidents to playbooks

Pillar 4: Simulation Report Template

Standardized after-action reporting for mock incident response drills.

Checklists:

  • Preparation Checklist — Prepare for mock drills, set goals, verify readiness
  • Execute and Observe — Track performance, document decisions, measure SLAs
  • After-Action Report — Document lessons learned, prevention plans, gaps

Pillar 5: Third-Party Incident Coordination

Manage vendor/SRE incidents with customers transparently and professionally.

Checklists:

  • Vendor Contact Matrix — Centralized vendor contact info (Stripe, SendGrid, CloudFlare, AWS, etc.)
  • Escalation Protocols — Define escalation steps, SLA tracking, and compensation
  • Customer Comms — Communicate vendor incidents transparently, manage expectations, provide compensation
