🔥 FIRST 5 MINUTES - Stop the Bleeding

0:00
DON'T PANIC - Take 30 seconds to breathe. Panic leads to mistakes.
0:30
DOCUMENT - Screenshot everything. Note times, error messages, affected systems.
1:00
ISOLATE - Unplug affected machines from network if you can't identify source.
2:00
PRESERVE - Don't reboot servers. Don't delete logs. Take memory dumps if possible.
3:00
CONTAIN - Change passwords. Block IPs. Disable compromised accounts.
4:00
ASSESS - What's affected? What's the impact? Who needs to know?
5:00
START LOGBOOK - Document every action, time, and decision from here.

📞 COMMUNICATION TEMPLATES

Immediate Alert (to management):
"Security incident detected at [time]. Affecting [systems]. We're containing now. Impact: [brief impact]. ETA for update: [time]."
Customer Notification:
"We're investigating a technical issue. Your data is secure. We'll provide updates every [X hours]. Thank you for your patience."
Team Alert:
"INCIDENT: [brief description]. All hands on deck. Channel: [Slack/Teams]. Do not post publicly. Follow incident response plan."
Status Update:
"Incident update: [What we know]. [What we're doing]. [Expected timeline]. [Impact on users]. Next update at [time]."

🔍 INVESTIGATION CHECKLIST

Review logs for unusual activity
Check firewall logs for blocked/allowed connections
Analyze authentication logs
Review recent changes/deployments
Check for unauthorized user accounts
Verify backup integrity
Scan for malware on affected systems
Review access permissions
Check data exfiltration indicators

🔄 RECOVERY STEPS

+1hr
ERADICATE - Remove malware. Patch vulnerabilities. Clean systems.
+2hr
RESTORE - Recover from clean backups. Verify integrity.
+3hr
VALIDATE - Test systems. Confirm no backdoors. Monitor closely.
+4hr
HARDEN - Implement new security controls. Update configs.
+24hr
REVIEW - What went well? What failed? Update procedures.

📋 POST-INCIDENT CHECKLIST

Document complete timeline
Identify root cause(s)
List all affected systems/data
Calculate business impact
Review response effectiveness
Update security procedures
Schedule follow-up activities
Conduct team debrief
Share lessons learned

⚡ QUICK REFERENCE

R
Ransomware? Isolate network immediately. Don't pay. Contact authorities.
D
Data Breach? Preserve evidence. Notify legal. Follow breach notification laws.
DDoS
DDoS Attack? Enable DDoS protection. Contact ISP. Monitor for secondary attacks.
I
Insider Threat? Preserve logs. Secure accounts. Contact HR/legal.
M
Malware? Isolate. Scan. Rebuild from scratch if needed.
